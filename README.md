# 배프 택시 연습 UI 시안

어르신이 택시 부르기를 연습하는 페이지의 임시 디자인 시안이에요. 실제로 호출되거나 결제되지 않아요.

3D 시작 화면이 있는 이전 버전은 with-3d-intro 브랜치에 있어요.

## 개발·연결 담당자 안내

- [AGENTS.md](AGENTS.md): 작업 원칙, 코드 구조, 기능별 주의사항, 검증 기준
- [PIPELINE.md](PIPELINE.md): 실행 흐름, 다른 페이지 연결, 메시지 형식, GitHub Pages·Cloudflare 배포와 복구 절차

프런트는 GitHub Pages에서 공개되고 Cloudflare Worker는 별도로 배포합니다. 코드 ZIP에는 비밀번호나 Worker Secret을 넣지 않습니다.

## 현재 호출 선택 화면

목록은 **대형택시 → 블루파트너스 → 일반호출** 순서입니다. 각 항목에 택시 아이콘과 설명이 있고, 요금은 “예상 7,100원” 형식으로 표시합니다. 기본 선택은 일반호출입니다.

다른 페이지에서 결과를 받는 담당자는 화면 이름과 기존 내부 key가 다른 점을 확인해 주세요. 결과 car는 일반(일반호출), 모범(블루파트너스), 대형(대형택시)으로 전달됩니다. 기존 요금 계산과 Worker 연결은 유지합니다. 세부 매핑과 점검 항목은 AGENTS.md와 PIPELINE.md에 있습니다.

선택 아이콘은 index.html 안의 SVG로 포함되어 있어 별도 이미지 파일을 전달할 필요가 없습니다.
